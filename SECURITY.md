# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub or the hosting provider. Include the affected URL/file, impact, reproduction steps, and remediation details. Do not publish credentials, database dumps, or personal data.

## Repository rules

- Never commit `wp-config.php`, `.env` files, credentials, tokens, private keys, database dumps, uploads, caches, or backups.
- Rotate credentials immediately if exposure is suspected.
- Use least-privilege access for GitHub and VPS accounts.
- Review changes before production deployment.
